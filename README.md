# كليتي الذكية · Smart College

موقع ملاحة عربي تفاعلي يعرض مبنى الكلية من الخارج، ثم يتيح الدخول إلى خرائط الأدوار الثلاثة والبحث عن المرافق وعرض مسار الوصول. المبنى والغرف والمسارات مرسومة برمجيًا باستخدام Three.js، مع خريطة SVG تفاعلية بديلة عند عدم توفر WebGL.

## التشغيل

للتجربة دون تثبيت أو تشغيل خادم، حمّلي ملف `smart-college-preview.html` وافتحيه مباشرة في Chrome أو Edge. يحتوي الملف على التطبيق والخطوط والمخطط، ويعمل دون اتصال. لإنشاء نسخة محدّثة منه من المصدر: `npm run preview:file`.

يتطلب Node.js 22.12 أو أحدث؛ اختُبر باستخدام Node.js 24.

```bash
npm ci
npm run dev
```

افتحي عنوان الخادم الذي يظهر في الطرفية. للتشغيل بعد بناء نسخة الإنتاج:

```bash
npm run build
npm run preview
```

## تجربة الموقع

1. يبدأ الموقع بالمبنى الخارجي. اضغطي على علامة «المدخل الرئيسي» أو زر «ادخلي المبنى» لفتح الدور الأرضي.
2. اختاري الأرضي أو الأول أو الثاني من لوحة الأدوار. استخدمي 2D/3D والتكبير والتدوير لتغيير العرض.
3. ابحثي عن «معمل» أو «مكتب» أو «المكتبة»، أو افتحي دليل المرافق. اختاري الوجهة واضغطي «أرشديني إلى هنا».
4. يبدأ المسار الأزرق عند المدخل. للوجهات في دور آخر، يُستخدم المصعد افتراضيًا؛ يمكن إلغاء الاختيار لاستخدام الدرج. تعرض أزرار الأدوار داخل بطاقة المسار كل جزء منه.
5. اضغطي على نقاط المصعد والسلالم ودورات المياه والمخارج لعرض معلوماتها. نقاط المصعد والسلالم تتيح اختيار الدور.

الواجهة تدعم الجوال والحاسب واتجاه الكتابة العربي. على الجوال يمكن طي لوحة البحث من المقبض العلوي. اختصار `Ctrl/Cmd + K` يفتح البحث، و`Escape` يغلق النافذة المفتوحة.

## مصدر المخطط وحدود الدقة

أعيد رسم توزيع الغرف اعتمادًا على الأدوار الثلاثة في الملف المرفق «المخطط (1).pdf»، المحفوظ في [public/college-plan.pdf](public/college-plan.pdf). يتضمن النموذج 10 معامل حاسب في الأرضي، و12 قاعة تدريبية في الأول، و11 في الثاني إضافة إلى المكتبة والمرافق الأخرى الظاهرة في الملف.

الأبعاد والارتفاعات تقريبية؛ لا يحتوي المرجع على مقياس رسم يمكن منه حساب مسافات واقعية. أرقام الغرف المتكررة للتمييز داخل النموذج وليست ترقيمًا رسميًا. المساحات غير المسماة في المرجع موضحة بهذا الاسم، دون افتراض تسميتها.

**الواجهة الخارجية وباب الدخول تصوريان** إلى حين توفير صورة المبنى والمدخل وقياساته. التوزيع الداخلي مستند إلى المخطط، ولا يُدّعى أنه نموذج هندسي مساحي.

## تطوير النموذج

### النشر على GitHub Pages

نسخة الموقع المبنية تُرفع إلى فرع `gh-pages`. لتفعيل الرابط من حساب مالك المستودع، افتحي **Settings → Pages → Source → Deploy from a branch** ثم اختاري **gh-pages** والمجلد **/(root)** واحفظي. يُبنى الموقع باستخدام `npm run build -- --base /desktop-tutorial/` حتى تعمل الخطوط والمخطط تحت مسار المستودع. رفع الملفات وحده لا يعني أن Pages مفعّلة؛ يُتحقق من رابط النشر بعد اكتمال التفعيل. لا يلزم جعل المستودع العام متاحًا لمجرد إعداد ملفات النشر؛ دعم Pages للمستودعات الخاصة يعتمد على خطة حساب GitHub.

- [src/data.ts](src/data.ts): الغرف، الأبواب، نقاط المرافق، حدود المبنى، وشبكة الممرات وحساب أقصر مسار.
- [src/scene.ts](src/scene.ts): الشكل الخارجي، الرسومات الداخلية، الكاميرا، النقر، والمسار الأزرق.
- [src/main.ts](src/main.ts): الواجهة العربية والبحث والأدوار وبطاقات التوجيه والخريطة البديلة.
- [src/style.css](src/style.css): تصميم الواجهة وتخطيط الجوال.

الخط العربي محلي ومضمّن في البناء. لا يحتاج تشغيل الموقع إلى خدمات خارجية أو مفاتيح API أو حسابات مدفوعة.

## التحقق

```bash
npm test
npm run build
npm run test:e2e
```

اختبارات البيانات تتحقق من توزيع الغرف، وإمكانية الوصول إلى كل باب، واتصال المسار بالمصعد أو الدرج، وعدم قطع غرف أخرى. اختبارات المتصفح تتحقق من الدخول والبحث والتوجيه والأدوار والعرض على الجوال وخريطة WebGL البديلة.

يستخدم إعداد Playwright متصفح Chromium النظامي إن كان متوفرًا في `/usr/bin/chromium`؛ وإلا يلزم تثبيت متصفح الاختبار عبر `npx playwright install chromium`.
